# python

Folder latihan dan catatan belajar bahasa pemrograman Python.

## Roadmap Python

### Tahap 1 — Fondasi
- [ ] Instalasi Python dan setup virtual environment (`venv`, `pip`)
- [ ] Sintaks dasar: variabel, tipe data, casting
- [ ] Operator aritmatika, perbandingan, logika
- [ ] Input/output dan string formatting (f-string)
- [ ] Struktur kontrol: `if`/`elif`/`else`, `for`, `while`
- [ ] Fungsi: parameter, default value, `*args`, `**kwargs`, return

### Tahap 2 — Struktur Data
- [ ] List dan operasinya (indexing, slicing, method)
- [ ] Tuple dan perbedaannya dengan list
- [ ] Dictionary dan set
- [ ] List/dict/set comprehension
- [ ] Unpacking, `*` operator, enumerate, zip

### Tahap 3 — Pilar OOP & Modularisasi
- [ ] Class, object, atribut, method, `__init__`
- [ ] Inheritance, encapsulation, polymorphism
- [ ] Magic/dunder methods (`__str__`, `__repr__`, `__eq__`, `__len__`)
- [ ] Module, package, dan `import`
- [ ] Exception handling (`try`, `except`, `finally`, `raise`)
- [ ] File handling dan `with` statement (context manager)

### Tahap 4 — Standar Library & Populer
- [ ] `datetime`, `math`, `random`, `os`, `pathlib`, `json`
- [ ] `collections`, `itertools`, `functools`
- [ ] Regex dengan `re`
- [ ] Virtual environment lanjutan: `pip freeze`, `requirements.txt`
- [ ] Testing dengan `unittest` dan `pytest`

### Tahap 5 — Spesialisasi
- [ ] Data analysis: `numpy`, `pandas`
- [ ] Visualisasi data: `matplotlib`, `seaborn`
- [ ] Web development: `flask` / `django` / `fastapi`
- [ ] Automation & scripting (REST API, web scraping dengan `requests`, `beautifulsoup4`)
- [ ] Database: `sqlite3`, `SQLAlchemy`, `psycopg`
- [ ] Async programming: `asyncio`, `aiohttp`
- [ ] Type hints, `mypy`, dan best practice (PEP 8, `black`, `ruff`)
